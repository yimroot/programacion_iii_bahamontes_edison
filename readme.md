## 🛠️ Tecnologías que veremos

### 🌐 HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para crear la **estructura de una página web**.

Nos permite trabajar con títulos, párrafos, imágenes, enlaces, formularios, tablas y diferentes secciones de una página.

> **Concepto clave:** HTML define la estructura y el contenido de una página web.

```html
<h1>Hola Mundo</h1>
<p>Mi primera página web</p>
```

---

### 🎨 CSS

**CSS (Cascading Style Sheets)** se utiliza para darle **estilo y diseño** a las páginas creadas con HTML.

Permite controlar colores, fuentes, tamaños, espacios, posiciones, animaciones y diseño responsive.

> **Concepto clave:** CSS se encarga de la apariencia y presentación de una página web.

```css
h1 {
    color: blue;
    font-size: 32px;
}
```

---

### ⚡ JavaScript

**JavaScript** es un lenguaje de programación que permite agregar **interactividad y comportamiento dinámico** a las páginas web.

Trabajaremos con variables, funciones, condicionales, ciclos, eventos, DOM, APIs y programación asíncrona.

> **Concepto clave:** JavaScript permite que una página web responda a las acciones del usuario.

```javascript
const nombre = "Edison";

console.log(`Hola ${nombre}`);
```

---

### 🔷 TypeScript

**TypeScript** es un lenguaje basado en JavaScript que agrega principalmente **tipado estático**, facilitando el desarrollo de aplicaciones grandes y mantenibles.

Trabajaremos con tipos, interfaces, clases, funciones y genéricos.

> **Concepto clave:** TypeScript ayuda a detectar errores durante el desarrollo y mejora la organización del código.

```typescript
let edad: number = 20;
let nombre: string = "Edison";
```

---

### 🦁 NestJS

**NestJS** es un framework para desarrollar aplicaciones **Backend utilizando Node.js y TypeScript**.

Permite crear aplicaciones organizadas y escalables mediante módulos, controladores, servicios, inyección de dependencias y APIs REST.

> **Concepto clave:** NestJS permite construir aplicaciones Backend estructuradas utilizando TypeScript.

```typescript
@Controller('usuarios')
export class UsuariosController {

    @Get()
    obtenerUsuarios() {
        return [];
    }
}
```

---

### ⚛️ ReactJS

**ReactJS** es una biblioteca de JavaScript utilizada para construir **interfaces de usuario** mediante componentes reutilizables.

Trabajaremos con componentes, props, estados, hooks, eventos y renderizado dinámico.

> **Concepto clave:** React permite construir interfaces dinámicas utilizando componentes reutilizables.

```jsx
function Saludo() {
    return <h1>Hola Mundo</h1>;
}

export default Saludo;
```
